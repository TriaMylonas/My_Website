Sep 2021

Add Barcode to PDF

A WPF application (C#) that allows users to insert barcodes into PDF documents. Documents cannot be manually modified once barcodes are entered and saved, ensuring data integrity.

Featured Project

Excel Bestandsvergleich

A Java desktop application that imports two Excel files and compares them. It generates a third Excel file containing only the differences between the two, which can then be saved by the user.
